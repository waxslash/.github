# `WAX://`

### Your records. Programmable.

A DJ library and set-building system for physical records.

Discogs knows *what the record is.* `WAX://` knows why you own it, what each track sounds like,
when you'd play it, what it mixes with, and where to find it when it's time to build a crate.

```
SET/NEW_

01 ┃ HOUSE/CHILL      ×03
   ↓
02 ┃ DUB/DEEP         ×02
   ↓
03 ┃ ROLE/BRIDGE      ×01
   ↓
04 ┃ DUB              ×02

08 TRACKS            [ BUILD_ ]
```

You describe the shape of a set. `WAX://` resolves it against the records you physically own.
